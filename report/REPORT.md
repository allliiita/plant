# 照片信号在未见物种性状预测中的价值：以冻结 ImageNet ViT-B + 岭回归为基准的预登记检验

## 一句话结论

在按属整群 bootstrap 的未见物种检验中，图像特征在属插补层面对四个性状均未超过分类学插补基线（ΔR² 全为负），但其增量 ΔR² 全为正；图像信号的价值随分类学距离增大而快速上升，在科/目层面转为大幅正增益，说明照片主要提供“超出近缘分类学先验”的补充信息，而非替代分类学基线。

## 研究问题与设计（5行内）

- 问题：在未见物种上，冻结 ImageNet ViT-B 图像特征 + 岭回归能否在分类学插补基线之上提升四个叶/株性状的预测？
- 数据：PlantTraitNet 发布数据（AAAI 2026），2,345 物种、69,952 张照片；10 个物种因有效照片<20 被剔除（0.42%）。
- 验证：按分类学 5 折交叉验证 + 按属整群 bootstrap 2000 次；主检验为属插补层（n=1,480）。
- 指标：ΔR² = image − imputation，报 95% CI 与 MDE（预登记功效模拟，n≈1,521）。
- 预登记规则：四性状分开报；不以“显著/不显著”二元措辞下结论；株高泄漏检查仅在主检验 CI>0 时触发。

- **Height**：ΔR² = -0.117 [-0.148, -0.089]，CI 不含零且为负；MDE 为 0.02/0.02/0.015，观测 ΔR² 为 -0.117。
- **LeafArea**：ΔR² = -0.225 [-0.295, -0.160]，CI 不含零且为负；MDE 为 0.05/0.05/0.045，观测 ΔR² 为 -0.225。
- **SLA**：ΔR² = -0.066 [-0.126, -0.005]，CI 不含零且为负；MDE 为 0.09/0.085/0.07，观测 ΔR² 为 -0.066。
- **Leaf_N**：ΔR² = -0.381 [-0.447, -0.312]，CI 不含零且为负；MDE 为 0.07/0.065/0.06，观测 ΔR² 为 -0.381。

四个性状的增量 ΔR²（在插补基线之上加入图像特征）均为正：Height +0.023 [+0.014, +0.034]、LeafArea +0.066 [+0.048, +0.086]、SLA +0.108 [+0.085, +0.133]、Leaf_N +0.026 [+0.015, +0.038]。即：单独用图像特征替代插补基线会损失预测力，但在插补基线之上叠加图像特征可带来小幅但 CI 不含零的正增量。

**株高规则说明**：株高主检验 ΔR²（image−imputation）CI 为 [-0.148, -0.089]，不含零且为负，未触发强制泄漏检查。需注意：株高增量 ΔR² 为正（+0.023 [+0.014, +0.034]），若未来在其它设定下增量 ΔR² 为正且幅度较大，应谨慎解读并主动排查泄漏（如照片元数据、拍摄尺度与株高的耦合）。

**叶片氮规则说明**：Leaf_N 图像 R²（0.167）未超过插补基线（0.548），未标“异常需检查”。其增量 ΔR² 为正（+0.026 [+0.015, +0.038]），可能部分来自叶色（叶绿素）信号，不能自动判为泄漏。

## 增量价值与器官控制

**增量 ΔR²（插补基线 + 图像 vs 仅插补）**：四性状均为正（见主检验表），SLA 最大（+0.108 [+0.085, +0.133]），LeafArea 次之（+0.066 [+0.048, +0.086]），Height（+0.023 [+0.014, +0.034]）与 Leaf_N（+0.026 [+0.015, +0.038]）较小。含义：图像特征携带插补基线未覆盖的信息，但单独替代基线不划算。

**器官控制（属插补层；加权 − 未加权 / top-10 − 未加权）**：

## 选择偏差检查

照片失效率 11.8%。失效率与性状对数的 Spearman 相关：

|---|---|---|---|
| Height | +0.192 | 871 | -0.107 [-0.135, -0.081] |
| LeafArea | +0.147 | 871 | -0.227 [-0.307, -0.148] |
| SLA | -0.061 | 871 | -0.067 [-0.142, +0.008] |
| Leaf_N | -0.068 | 871 | -0.374 [-0.454, -0.283] |

**专段说明（规则要求：ρ>0.1 需专段）**：Height（ρ=+0.192）与 LeafArea（ρ=+0.147）的照片失效率与性状正相关，即株高/叶面积较大的物种，其照片失效率往往更高，存在潜在选择偏差。敏感性分析只保留同属插补层中照片失效率 ≤ 中位数的物种（n=871）后，Height ΔR² = -0.107 [-0.135, -0.081]、LeafArea ΔR² = -0.227 [-0.307, -0.148]，与全样本主检验（-0.117、-0.225）方向与量级一致，未见偏差驱动结论反转。SLA（ρ=-0.061）与 Leaf_N（ρ=-0.068）失效率相关性低于 0.1 阈值，敏感性分析结果（-0.067 [-0.142, +0.008]、-0.374 [-0.454, -0.283]）亦与主检验一致。

## 可靠性证据（要点列表）

- **样本流水线完整**：2,355 个物种进入流程，剔除 10 个（0.42%），最终 2,345 个物种、69,952 张照片进入分析；临时下载失败 0 次。
- **照片失效率**：全流程照片失效率 11.8%，并已作为敏感性分析对象（见“局限”）。
- **重跑一致性**：分析在不同机器上重跑，结构一致，最大数值差为 0。
- **离线测试**：离线测试 14/14 通过；变异检查 14/14 通过，每个变异均由专门测试捕获。
- **分阶段放行**：冒烟（60 种）与试点（240 种）全部门槛通过后才运行全量。
- **花钱前拦截**：离线已知答案测试在产生计算开销前抓出 3 个 bug，其中包括增量 R² 设计错误。
- **统计设计**：分类学 5 折交叉验证，并按属整群 bootstrap 2,000 次；内部检查采用 Holm 校正的单侧 bootstrap p，四个性状均未触发额外检查（Height p=1.000，LeafArea p=1.000，Leaf_N p=1.000，SLA p=0.983）。

## 结果的含义

- **照片模型在同属内不及属均值插补，但带有小幅增量信息**：属插补层（n=1,480）中，Height 的 ΔR² 为 -0.117 [-0.148, -0.089]，LeafArea 为 -0.225 [-0.295, -0.160]，SLA 为 -0.066 [-0.126, -0.005]，Leaf_N 为 -0.381 [-0.447, -0.312]；而在同一层内，增量 ΔR² 分别为 +0.023 [+0.014, +0.034]、+0.066 [+0.048, +0.086]、+0.108 [+0.085, +0.133]、+0.026 [+0.015, +0.038]。即照片信号在属均值之外仍有可测增量，但不足以弥补与属均值的整体差距。
- **分类学距离越大，照片的相对价值越高**：以 Height 为例，留出 Species 时 ΔR² 为 +0.025 [-0.008, +0.061]，留出 genus 时升至 +0.337 [+0.236, +0.452]，留出 family 时 +0.709 [+0.567, +0.876]，留出 order 时 +0.819 [+0.786, +0.858]；跨目（order_or_global 层，n=98）照片模型 R² 仍达 0.701，pooled 层 R² 为 0.769（ΔR² +0.025 [-0.008, +0.061]）。LeafArea 与 SLA 呈同向格局（如 LeafArea 留出 family 时 ΔR² +0.528 [+0.409, +0.659]）。
- **叶片氮的照片信号弱**：Leaf_N 在属插补层 R² 仅 0.167（插补 0.548，ΔR² -0.381 [-0.447, -0.312]），pooled 层 R² 0.154（ΔR² -0.257 [-0.310, -0.205]）；即便留出 family/order 时 ΔR² 转正（+0.232 [+0.144, +0.326]、+0.126 [+0.092, +0.158]），绝对 R² 仍低（0.092、0.073）。
- **热身实验否定“回归=认物种”捷径**：已见物种、图像层级下，最近质心查表的 R² 对 LeafArea、SLA、Leaf_N 为负（-0.215、-0.335、-0.574），而直接回归为 0.305、0.229、0.100；说明该冻结 ImageNet backbone 的物种辨识能力弱，模型学到的更像生长型等粗粒度线索，而非以物种身份为中介。
- **器官软权重带来小幅、方向不一的修正**：属插补层中，加权减未加权对 LeafArea 为 +0.029 [+0.014, +0.045]、SLA 为 +0.016 [+0.005, +0.026]、Leaf_N 为 +0.010 [+0.001, +0.019]，Height 为 -0.010 [-0.021, +0.001]；top-10 加权与未加权之差量级相近。

## 局限

- **无从头训练 CNN 对照**：没有从头训练的模型作为对照，因此不能完全排除 ImageNet 预训练本身带来的植物信号（预训练中含部分植物类别）。
- **无 AusTraits 长宽比尺度校准对照**：没有尺度无关的形状性状作为正对照，因此对株高、叶面积这类尺寸性状，无法区分“照片本身没有信息”与“市民科学照片缺少尺度（无比例尺）”。
- **≥30 张照片物种的选择偏差**：仅纳入照片数 ≥30 的物种，构成选择偏差，结论不能直接外推到照片稀少的物种。
- **照片失效率与性状相关**：照片失效率与株高、叶面积正相关（Spearman ρ 分别为 +0.192、+0.147）；低失效率子集敏感性分析（n=871）中，Height ΔR² -0.107 [-0.135, -0.081]、LeafArea -0.227 [-0.307, -0.148]、SLA -0.067 [-0.142, +0.008]、Leaf_N -0.374 [-0.454, -0.283]，与主分析（-0.117、-0.225、-0.066、-0.381）方向和量级都很接近；失效并非完全随机，但在本检验中未改变结论。
- **器官标签一致率有限**：PlantCLEF 器官标签与本研究定义的一致率约 47%（n=30，由 Claude 标注、非专家），故采用软权重而非硬过滤；器官控制结果（如 LeafArea 加权−未加权 +0.029 [+0.014, +0.045]）应在此标签噪声下解读。
- **模型族受限**：仅使用冻结 ImageNet ViT-B + 岭回归，结论限于该模型族，不等于 PlantTraitNet 原模型的表现。
- **MDE 来源**：最小可检测效应（MDE）来自预登记功效模拟（n≈1,521），实际分析 n=1,480，二者不完全一致。

## 简历 bullet（英文）

- **Diagnostic finding**: On the PlantTraitNet citizen-science dataset (2,345 species, 69,952 iNaturalist photos), showed that for species with congeners in training, a photo-based trait model (frozen ViT-B + ridge) underperforms a no-image genus-mean baseline on all four traits (ΔR² −0.066 to −0.381) and adds only +0.023 to +0.108 R² on top of it; photos outperform taxonomy only once the taxonomic neighbourhood is missing (Height ΔR² +0.337 at unseen genera, +0.819 at unseen orders).
- **Evaluation protocol & reliability**: Built a pre-registered, taxonomically blocked benchmark (species/genus/family/order held-out CV, genus-clustered bootstrap, taxonomic-imputation baselines) on a reliability harness — offline known-answer and fault-injection tests (14/14), mutation check (14/14), staged smoke/pilot gates, cross-machine reproducibility — which caught 3 analysis bugs, including a biased incremental-R² design, before any paid run.

## 后续实验建议

- **加入从头训练 CNN 对照**：在同一分类学 5 折与按属 bootstrap 框架下训练小型 CNN，与冻结 ViT-B + 岭回归直接对比，界定性能差距来自 backbone 还是任务。
- **引入 AusTraits 长宽比尺度校准对照**：以 AusTraits 长宽比信息校准叶片尺度后重估 LeafArea/SLA，检验尺度效应能否解释属插补层中的负 ΔR²。
- **提高器官标签质量**：对 PlantCLEF 器官标签做专家复核或扩大标注样本（当前 n=30、一致率约 47%），再比较软权重与硬过滤的增量差异。
- **失效率加权与缺失机制建模**：针对失效率与株高/叶面积的正相关（ρ +0.192/+0.147），采用逆概率加权或显式缺失机制模型，检验低失效率子集结果（n=871）与主分析的偏差来源。
- **扩展模型族与表征**：在冻结 ViT-B 之外测试其他冻结 backbone 与轻量微调方案，检验“粗粒度线索为主”的机制结论是否随表征变化。
